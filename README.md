# Madhav-Ecommerce-Sales-PowerBI-Dashboard
📊 Project Overview

The Madhav E-commerce Sales Dashboard is an interactive business intelligence project developed using Microsoft Power BI.

The dashboard analyzes e-commerce sales performance across different dimensions such as sales amount, profit, quantity, customers, product categories, sub-categories, payment modes, states, and cities.

The goal of this project is to transform raw e-commerce data into meaningful business insights that can help understand sales performance and identify profitable products, regions, and customer trends.

🎯 Business Objectives

The main objectives of this dashboard are:

Monitor overall sales performance.
Analyze total profit and profitability trends.
Understand product category and sub-category performance.
Identify high-performing and low-performing products.
Analyze sales across different states and cities.
Understand customer purchasing patterns.
Analyze different payment methods used by customers.
Track order quantity and sales trends over time.
Provide an interactive dashboard for business decision-making.
🛠️ Tools & Technologies
Power BI – Dashboard development and data visualization
Power Query – Data cleaning and transformation
DAX – Measures and calculated metrics
Microsoft Excel / CSV – Data source
GitHub – Project documentation and version control
📁 Dataset

The project uses two datasets:

Orders Dataset

The Orders.csv file contains information related to customer orders.

Important columns include:

Order ID
Order Date
Customer Name
State
City
Details Dataset

The Details.csv file contains information about products and transactions.

Important columns include:

Order ID
Amount
Profit
Quantity
Category
Sub-Category
Payment Mode

The two datasets are connected using Order ID.

📌 Key KPIs

The dashboard focuses on important business metrics such as:

Total Sales / Amount
Total Profit
Total Quantity
Average Order Value (AOV)
Number of Orders
Customer Performance

These KPIs provide a quick overview of overall business performance.

📈 Dashboard Analysis
Sales Analysis

The dashboard provides an overview of sales performance and helps identify trends in revenue over time.

Profit Analysis

Profit is analyzed across different categories, sub-categories, regions, and time periods to identify the areas contributing most to overall profitability.

Product Analysis

The dashboard analyzes:

Product categories
Product sub-categories
Sales amount
Profit
Quantity

This helps identify the best-performing product segments.

Geographical Analysis

Sales performance can be analyzed by:

State
City

This helps identify high-performing geographical regions.

Payment Mode Analysis

The dashboard analyzes different payment methods, such as:

COD
EMI
Other available payment modes

This provides insight into customer payment preferences.

🔄 Data Preparation

The data was prepared using Power Query before creating the dashboard.

The data preparation process included:

Importing the Orders and Details datasets.
Checking column data types.
Cleaning and formatting the data.
Checking for duplicate records.
Handling missing or inconsistent values where required.
Creating the relationship between the datasets using Order ID.
Preparing the data for analysis in Power BI.
🧮 DAX & Calculations

DAX measures were used to calculate important business metrics such as:

Total Sales
Total Profit
Total Quantity
Average Order Value
Order Count
Profit-related KPIs

These measures allow the dashboard visuals to dynamically respond to filters and slicers.

🎛️ Dashboard Interactivity

The dashboard includes interactive filters/slicers that allow users to analyze the data based on different dimensions.

When a slicer is selected, the dashboard visuals dynamically update according to the selected criteria.

This makes it possible to perform interactive analysis rather than viewing static reports.

💡 Key Insights

The dashboard can be used to identify:

Which product categories generate the highest sales.
Which categories and sub-categories generate the highest profit.
Which states and cities contribute most to sales.
Customer purchasing patterns.
Preferred payment methods.
Sales and profit trends over time.
Areas where business performance can be improved.
